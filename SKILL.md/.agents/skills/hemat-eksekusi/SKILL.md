# Langkah Kerja Bertahap

1. **Tentukan Target:** Sebutkan maksimal 3 file utama yang akan diubah.
2. **Kerjakan Satu per Satu:** Selesaikan satu fungsi atau komponen terlebih dahulu, lalu uji sebelum lanjut ke bagian lain.
3. **Ringkas Log Terminal:** Jalankan perintah terminal dengan mode ringkas (seperti `--quiet` atau `--silent`) agar log panjang tidak memakan kuota konteks.
